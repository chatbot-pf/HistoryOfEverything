# Product Guidelines: The History of Everything

## UX 원칙
1. **시각적 몰입**: 애니메이션과 인터랙션이 학습 경험의 핵심
2. **직관적 탐색**: 스크롤/줌 제스처로 자연스럽게 탐색
3. **정보 계층화**: 타임라인 → 버블 → 아티클 순으로 점진적 상세화
4. **성능 우선**: 애니메이션이 스크롤 성능을 저해하지 않도록 최적화

## 디자인 스타일
- **글꼴**: Roboto (Regular, Medium)
- **색상**: 어두운 배경에 밝은 액센트 (우주/역사 테마)
- **레이아웃**: Material Design 기반, 커스텀 위젯 활용
- **아이콘**: Cupertino Icons + 커스텀 애니메이션 아이콘

## 콘텐츠 가이드라인
- 아티클은 Wikipedia 기반, 교육적 톤 유지
- 사건 설명은 간결하고 접근성 있게
- 애니메이션은 사건의 핵심을 시각적으로 전달

## 개발 가이드라인
- 커스텀 RenderObject를 활용한 고성능 렌더링
- BLoC 패턴으로 상태와 UI 분리
- Flare/Nima 애니메이션은 `SchedulerBinding` 활용
- 로컬 에셋 기반 오프라인 우선 설계
